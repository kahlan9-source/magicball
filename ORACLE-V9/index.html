TOUJOURS DANS TA POCHE

Un oracle à domicile.

Installe MFM Oracle sur ton écran d’accueil. Aucun App Store, aucun abonnement.

  1. 01
    Ouvre cette page dans Safari sur ton iPhone.
  2. 02
    Touche Partager (parfois dans le menu …), puis Sur l’écran d’accueil.
  3. 03
    Active Ouvrir comme app web si proposé, puis touche Ajouter.

Lance l’app une fois avec Internet et attends « Prêt hors ligne ». L’oracle fonctionnera ensuite sans réseau.

Sur Android ou ordinateur : utilise aussi « Installer l’application » dans le menu du navigateur.
